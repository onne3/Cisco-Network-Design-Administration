Week 7 — Network Troubleshooting and Recovery
Objective

The objective of this practical was to design a functioning network, introduce physical and logical failures, observe their effects and implement recovery actions.

Tools Used
Cisco Packet Tracer
Cisco Routers
Cisco Switches
End Devices
Ping and network verification tools
Practical Activities
Designed a network topology using Cisco routers, switches and endpoints.
Configured IP addresses, subnet masks and routing.
Documented the initial network state.
Used ping to verify connectivity.
Simulated a physical failure by disconnecting a cable.
Simulated a logical failure by disabling a router or switch interface.
Observed connectivity loss, packet loss and network status changes.
Implemented physical and logical recovery actions.
Reconnected network components and restored disabled interfaces.
Performed connectivity tests to verify recovery.
Evidence

Screenshots in this folder document the network topology, failure simulation, observations, recovery actions and connectivity testing.

Key Learning

This practical developed my troubleshooting and recovery skills by demonstrating how physical and logical network failures affect connectivity and how network administrators can restore normal operation.
