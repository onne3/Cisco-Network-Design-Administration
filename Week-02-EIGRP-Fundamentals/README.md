Week 2 — EIGRP Fundamentals
Objective

The objective of this practical was to introduce Enhanced Interior Gateway Routing Protocol (EIGRP) and develop an understanding of dynamic routing between network devices.

Tools Used
Cisco Packet Tracer
Cisco Routers
Cisco Switches
End Devices
Practical Activities
Built a simulated network topology.
Configured network addressing.
Implemented EIGRP routing.
Verified routing information and network connectivity.
Tested communication between network devices.
Evidence

Screenshots in this folder document the EIGRP configuration and verification activities.

Key Learning

This practical introduced dynamic routing using EIGRP and demonstrated how routers can exchange routing information to establish connectivity across a network.
