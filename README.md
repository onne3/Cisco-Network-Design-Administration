# Cisco Network Design & Administration

A 10-week practical networking project completed as part of my Diploma in Information Technology (Network Design and Administration) at CTU Training Solutions.

The project uses Cisco Packet Tracer to develop practical skills in network design, IP addressing, routing, switching, network services, troubleshooting and network security.

## Project Overview

The practical work covered a progression of networking concepts, beginning with IPv4/IPv6 addressing and routing and progressing through dynamic routing protocols, VLANs, network services, troubleshooting and security.

The repository contains screenshots documenting the practical work completed throughout the project.
