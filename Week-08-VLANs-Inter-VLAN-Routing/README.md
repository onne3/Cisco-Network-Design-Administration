Week 8 — VLANs and Inter-VLAN Routing
Objective

The objective of this practical was to develop an understanding of VLAN segmentation and communication between VLANs.

Tools Used
Cisco Packet Tracer
Cisco Switches
Cisco Routers
End Devices
Practical Activities
Created and configured VLANs.
Assigned devices to appropriate VLANs.
Configured trunking between network devices.
Implemented inter-VLAN routing.
Tested communication between network segments.
Evidence

Screenshots in this folder document the VLAN, switching and inter-VLAN routing configuration.

Key Learning

This practical demonstrated how VLANs can be used to logically segment a network and how inter-VLAN routing enables communication between separate VLANs.
